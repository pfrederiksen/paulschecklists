Import notes

Partial import. All 243 physical subject/source rows / 16 sections and all 119 literal family guide terms are imported. Three printed dash placeholders remain explicit unresolved number/subject fields; no missing 49 or TH-8 is inferred. The standalone printed 0 has no card identity and is retained as source context.
